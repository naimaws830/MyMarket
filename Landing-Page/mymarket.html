How a headline becomes an alert

1

Reads the news

Pulls fresh stories from live Malaysian feeds: Malay Mail, Bernama and Free Malaysia Today. It fetches each article's text at one request per second, following each site's robots.txt.

2

Finds the food

Three checks, cheapest first: English and Malay names like ayam and telur, a price word such as harga, subsidy or shortage in the headline, then a meaning check, so a chicken rice review isn't read as a poultry price story.

3

Calls the direction

A trained model gives the chance the shelf price goes up, down or stays stable over the next 28 days. If it's under 55% sure, it says nothing instead of guessing.

4

Checks official prices

Shows the product's latest price level and its 7-day and 30-day change from PriceCatcher, and notes whether the real numbers agree with the call.

5

Says what to do

Scores urgency out of 100 from confidence, direction, price agreement and how fresh the story is, then picks ACT NOW, WATCH, MONITOR or NO ACTION with a concrete next step. Only calls at 70% confidence or above can reach ACT NOW.

6

Explains why

Links the trigger to one of 26 known causes, like feed costs, floods, bird flu or subsidy changes. The server hands your chat app only computed facts and writes no sentences itself, so it can't invent a number.

It tells you when it isn't sure

News is a weak signal for grocery prices, and only 305 labelled examples could be built from 153,981 articles. MyMarket is an awareness alert, not a forecast, and it keeps its own report card.

Status: hackathon MVP, version 0.4. On 40 held-out test cases the model scores macro F1 0.333 against 0.315 for simple price momentum, with a 95% interval of 0.218 to 0.449. That is a tie, not a win. Alerts at 70% confidence or above were right 0.70 of the time across 20 alerts. Run backtest_report for the full report.

It can say nothing

Under 55% confidence, it abstains rather than guess.

It has to beat simple rivals

The model is compared with always guessing the most common outcome, the price trend over the 28 days before the article, and plain keyword rules. If it doesn't win, the report says so.

No peeking at the future

It's tested on newer articles than it learned from, with a 28-day gap in between, and re-tested quarter by quarter.

The AI can't make up figures

The server sends only the model's output and computed facts in a strict format, and by default writes no sentences itself. Every explanation says it is the known cause, not a readout of the model's internals.

Live calls get marked later

Every prediction is logged, then scored against fresh prices 28 days on. No live calls have matured yet.

It shows its misses

Demo cases include wrong calls, like a 95% confident "stable" that was wrong.

One news source, for now

It learned from The Star only and runs live on other outlets, so live use is a test it hasn't seen.

Connect it to Claude

Use the hosted endpoint, or run it yourself. It runs on a laptop with 8 GB of RAM and no GPU. Every data source is free.

1

Use the remote endpoint

Add this URL as a custom connector in Claude, or point any MCP client that speaks streamable HTTP at it. It is live only while the demo server is running.

https://mymarket-my.loca.lt/mcp
2

Or run it locally: test in MCP Inspector

Run this in the project folder, open the link it prints, then call list_domains and scan_alerts.

npx @modelcontextprotocol/inspector uv run python -m mymarket.mcp_server
3

Add it to Claude Desktop

Open the config file and paste this in. On Mac it's ~/Library/Application Support/Claude/claude_desktop_config.json. On Windows it's %APPDATA%\Claude\claude_desktop_config.json. Replace /ABSOLUTE/PATH/mymarket with the folder where you cloned the repo.

{
  "mcpServers": {
    "mymarket": {
      "command": "uv",
      "args": ["--directory", "/ABSOLUTE/PATH/mymarket", "run", "python", "-m", "mymarket.mcp_server"]
    }
  }
}
4

Restart and ask

Fully quit and reopen Claude Desktop, check the tools icon, then ask what news could affect food prices.
